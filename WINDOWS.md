# ProxyYou для Windows x64

Клиент рассчитан на Windows 10/11 x64. Бинарные файлы x64 также могут запускаться через эмуляцию в Windows 11 ARM64. Интерфейс и установщик — на русском языке. Добавление и обновление подписок, кнопки подключения и пинга, обработка больших списков и лимит 20 проверок используют общий код клиента.

Сетевая проверка обращается к `https://www.youtube.com/generate_204` и тестовой миниатюре через текущий прокси. Отображаются доступность и время ответа. В Windows начиная с 4.1.23 проверка воспроизведением и зависимость WebView2 удалены. Сетевая проверка не подтверждает воспроизведение видео.

## Установка

Установочный файл: `ProxyYou-Windows-x64-4.1.24-Setup.exe`. Поставка — один EXE-установщик, который размещает необходимые DLL и ресурсы рядом с программой. Установщик размещает программу в папке текущего пользователя; TUN при подключении может отдельно запросить права администратора.

Приложение основано на Hiddify; исходная лицензия сохранена. Нативный помощник имеет имя HiddifyCli.exe, поскольку это имя ожидает ядро. Сам клиент, его окно и mutex имеют имя ProxyYou.

## Сборка

1. Установите Flutter 3.47.7 (Dart 3.13.5) и Visual Studio 2022 с компонентами C++ для рабочего стола, Windows SDK и CMake. Для создания установщика добавьте Inno Setup 6.3+.
2. Подготовьте нативное ядро Hiddify Core v4.1.0 с подмодулями на закреплённых коммитах, Go 1.25.6 и x64 MinGW. На Linux/macOS выполните `scripts/build-windows-core.sh /path/to/hiddify-core`; можно задать CC для LLVM-MinGW. Патч ограничения проверок находится в native-patches/youtube-monitoring.patch.
3. Убедитесь, что hiddify-core/windows-x64 содержит hiddify-core.dll, libcronet.dll и HiddifyCli.exe. Готовые macOS/Android-библиотеки для Windows не подходят.
4. В PowerShell из папки проекта выполните `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-windows.ps1 -InstallerOnly`. Скрипт запускает тесты, явно собирает windows-x64 и создаёт только установщик EXE; при -InstallerOnly наличие ISCC.exe обязательно.
5. Результаты и SHA-256 находятся в out. Все необходимые DLL Visual C++ включаются в приложение через существующий плагин vclibs.

Сборка для Windows должна выполняться на Windows; [инструкция Flutter](https://docs.flutter.dev/platform-integration/windows/building).

При переключении между окном ProxyYou и браузерами служба ядра и её подписки на состояние и журналы сохраняются. Повторный фокус окна не запускает инициализацию службы; мобильные платформы продолжают обновлять foreground-канал при возвращении из фона.

Проверка 4.1.17: в Windows 11 на локальном стенде с изолированными данными 60 переключений между клиентом и Edge, 109 запросов через ядро и 69 запросов Edge завершились без обрыва. Браузер использовал явный адрес локального прокси. Системные настройки остались прежними; пользовательские подписки и видео этим тестом не проверялись.
