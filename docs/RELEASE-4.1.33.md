# ProxyYou 4.1.33

- macOS и Android: успех после 12 секунд непрерывного воспроизведения с декодированными кадрами.
- Подтверждённый успех сохраняется при паузе, перемотке, окончании ролика и закрытии плеера; окно остаётся открытым для досмотра.
- При закрытии считывается последнее подтверждение. Новая проверка не наследует результат предыдущей.
- Windows: проверка воспроизведения по-прежнему отключена.

macOS: Apple Silicon, macOS 14+, подпись ad-hoc, без нотариализации Apple.
Android: прежняя подпись, ARMv7/ARM64/x86_64, Java 25.
Windows x64: установщик EXE без цифровой подписи.
