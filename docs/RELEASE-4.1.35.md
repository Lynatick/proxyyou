# ProxyYou 4.1.35

- Ускорено обновление больших списков: счётчики изменений вместо полного обхода результатов пинга.
- Сокращены повторные сортировки во время проверки серверов; стабильные номера конфигураций сохраняются.
- Загружаются и обновляются страницы вокруг видимой области; проверены дальняя прокрутка, возврат и клавиатурный фокус.
- Потоковый осмотр скачанной подписки уменьшает пиковый расход памяти, поддерживает UTF-8, base64 и агрегаторы URL.
- Обновлена схема БД с сохранением подписок и проверкой атомарной миграции.

macOS Apple Silicon, Android/TV и Windows x64. macOS Intel не поддерживается.

Подпись macOS: локальная ad-hoc, без Apple notarization. Android: прежний локальный сертификат. Windows: без Authenticode. Сборки и проверки выполняются локально.
