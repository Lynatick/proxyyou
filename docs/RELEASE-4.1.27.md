# ProxyYou 4.1.27

- Конфигурации подписок переведены в таблицы SQLite: одна запись на сервер, параметры в типизированных полях.
- Ядро загружает конфигурации из БД и создаёт протоколы по необходимости.
- Обновление подписки сохраняет действующие соединения; при ошибке применения восстанавливается прежняя версия.
- Большие списки загружаются страницами, результаты проверок и выбор серверов сохраняются в БД.
- Исправлено открытие служебной БД на Android TV и других устройствах с эмулируемым внешним хранилищем.
- Логирование по умолчанию отключено. Диагностику можно включить в настройках.

macOS: отдельные Apple Silicon и Intel ZIP, подпись ad-hoc, без нотариализации Apple. Windows x64: установщик EXE без цифровой подписи. Android: прежний сертификат подписи для обновления поверх установленной версии.
