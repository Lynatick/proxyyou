# ProxyYou 4.1.31

- Названия конфигураций занимают одну строку и обрезаются с троеточием.
- У серверов появились постоянные номера внутри подписки; доступен прямой и обратный порядок сортировки по номеру, названию, задержке и трафику.
- «Доступность YouTube» стала кнопкой с подсказкой «Тестовое видео»; отдельная кнопка воспроизведения удалена.
- Сетевая проверка выполняется автоматически после подключения и смены маршрута; результат с задержками и ошибками показан под миниатюрой. Предпросмотр загружается только через прокси.
- Удалены нижние подсказки и пояснения.
- macOS Intel исключён из новых выпусков и со страницы загрузки.

macOS: только Apple Silicon, минимальная версия macOS 14.0, локальная ad-hoc подпись, без нотариализации Apple.
Android: сохранена прежняя подпись приложения, ARMv7 / ARM64 / x86_64, Java 25.
Windows x64: установщик EXE без цифровой подписи; проверка декодирования видео отключена, кнопка открывает тестовое видео во внешнем браузере.
