# ProxyYou 4.1.30

Ускорена обработка подписок на macOS, Android и Windows. Проверка обновлений сохраняет полученный файл в закрытом временном кэше на срок до пяти минут; ручное обновление использует эту копию без повторного скачивания. Разбор выполняется в фоне, хеш и заголовки извлекаются за один проход.

Запись конфигураций в БД выполняется пакетами по 1024 с одним подготовленным запросом полей на пакет. Сохраняются WAL, полная фиксация на диск и активация новой версии только после успешного импорта. Ошибка промежуточного пакета сохраняет прежнюю активную подписку. Ядро повторно использует уже прочитанный входной файл.

Пакеты: macOS Apple Silicon и Intel отдельно, Android APK, Windows x64 EXE. macOS использует подпись ad-hoc, Windows-установщик не имеет коммерческой цифровой подписи. Android сохраняет прежний сертификат обновления.
