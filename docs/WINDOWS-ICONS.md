# Значки Windows

Для Windows используется отдельный набор графики в стиле Fluent. EXE, ярлыки
и установщик используют `windows/runner/resources/app_icon.ico`; графика
на экранах знакомства и «О программе» — `assets/images/windows/app_icon.png`.
Редактируемый векторный оригинал — `windows/runner/resources/app_icon.svg`.

Значки трея находятся в `assets/images/windows`. Есть светлый и тёмный варианты
для состояний «отключено», «подключение», «подключено» и «ошибка». Состояния
различаются формой индикатора и цветом. Контрастный контур сохраняет читаемость
при разной теме панели задач и приложений. При изменении системной яркости
значок трея обновляется; прежняя последовательная обработка обновлений сохранена.

`PlatformIcon` использует контурные Fluent UI glyphs на Windows. На остальных
платформах сохраняется исходный IconData и обычное поведение Flutter Icon.
Размер, цвет, семантические подписи, направление и настройки масштабирования
передаются без изменений. Шрифты Windows не извлекаются из ОС: используется
уже подключённый пакет `fluentui_system_icons`, новые зависимости не добавлены.
Исходные изображения других платформ остаются прежними.

Генератор только для Windows:

```sh
xcrun swift tools/generate_windows_icons.swift "$PWD"
```

Он создаёт ICO с самостоятельными растровыми представлениями 16, 20, 24, 32,
40, 48, 64 пикселя; у значка приложения также 96, 128 и 256. Общий генератор
`generate-proxyyou-assets.swift` для изменения только Windows запускать не надо.

Проверки: выбор Fluent glyphs и сохранение исходных на других платформах,
цвет/размер/семантика виджета, ресурсы светлой/тёмной темы, состояния трея,
структура ICO и соответствие значков установщика и приложения.

Ориентир дизайна: [рекомендации Microsoft](https://learn.microsoft.com/en-us/windows/apps/design/iconography/app-icon-design).
