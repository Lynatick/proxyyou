# ProxyYou 4.1.25

Ошибки проверки доступности теперь важнее положительного пинга.

- Ошибки HTTP, TLS, сети и миниатюр помечают конфигурацию «Недоступна».
- Balance и lowest исключают её для новых соединений до успешной полной перепроверки.
- Открытые соединения сохраняются; отменённые и устаревшие проверки не блокируют сервер.
- Проверка закреплена за конкретным сервером. Общий лимит проверок — 20.
- Недоступность видна в списке и на главной; кнопка отключения остаётся доступной.

Поддерживаются macOS Apple Silicon и Intel (раздельные ZIP), Android / Android TV
(единый APK для armv7, arm64 и x64), Windows x64 (установщик EXE).
На Windows проверка воспроизведения видео отключена.

macOS: локальная ad-hoc подпись, без нотарификации Apple.
Windows: установщик без цифровой подписи издателя.
Android: сохранён прежний сертификат подписи, возможно обновление поверх предыдущей версии.

Сборки и проверки выполнены локально. Android — Java 25, Windows — временный файл подкачки.
Страница загрузки и ссылка обновления: https://lynatick.github.io/proxyyou/
