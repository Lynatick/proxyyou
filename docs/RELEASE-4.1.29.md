# ProxyYou 4.1.29 — Windows x64

Обновлены значки приложения, установщика, кнопок и области уведомлений в стиле
Fluent. Добавлены отдельные варианты трея для светлой и тёмной темы и состояний
подключения, ожидания и ошибки. Значки содержат изображения для малых размеров
и экранов с повышенным масштабом.

В этом выпуске обновлён только Windows x64, пакет — EXE. Для macOS и Android
на сайте остаётся версия 4.1.28. Нативное ядро и настройки подключения не менялись.

Установщик Windows не имеет коммерческой цифровой подписи. Подписки сохраняются
при обычном обновлении поверх предыдущей версии.
