# ProxyYou 4.1.28

Исправлено автоматическое обновление порядка конфигураций после проверки пинга.
При сортировке по задержке учитывается вся подписка, включая ещё не загруженные
страницы. Выбор сервера сохраняется; страницы обновляются без дубликатов.
Исправлена очистка списка при закрытии во время обновления. Без новых результатов
повторная сортировка не выполняется. Проверена подписка из 50 000 конфигураций.

Пакеты: Android (ARMv7/ARM64/x86_64), Windows x64 (EXE), macOS Apple Silicon
и Intel (отдельные ZIP, macOS 14 или новее).

Android сохраняет прежнюю подпись. macOS имеет локальную подпись (ad-hoc),
не нотарифицирован Apple; Windows EXE не имеет коммерческой цифровой подписи.
Intel: проверены сборка, архитектура и подпись; запуск на Intel Mac в этой среде
недоступен. Нативное ядро совпадает с проверенным ядром 4.1.27.
