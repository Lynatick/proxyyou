# ProxyYou 4.1.32

- С главного экрана удалено изображение тестового видео и его дополнительная загрузка.
- Результаты YouTube, миниатюр и воспроизведения показаны в трёх отдельных строках.
- Возвращены значки успеха и ошибки; ожидание, выполняющаяся и отменённая проверка обозначаются значком часов.
- Сохранены автоматическая сетевая проверка и открытие тестового видео по заголовку.

По прямому указанию пользователя тестирование, статический анализ и проверки запуска этого выпуска пропущены, в том числе в CI. Сборка и упаковка выполнены; контрольные суммы файлов приложены.
macOS: только Apple Silicon, macOS 14+, подпись ad-hoc, без нотариализации Apple.
Android: прежний сертификат подписи, ARMv7 / ARM64 / x86_64, Java 25.
Windows x64: установщик EXE без цифровой подписи; проверка воспроизведения видео отключена.
