# ProxyYou 4.1.34

- Проверки выполняются последовательно: пинг, YouTube, миниатюра, 12 секунд видео с подтверждёнными кадрами.
- Ошибка помечает конфигурацию недоступной и переводит новые соединения на другую конфигурацию. Уже установленные соединения не закрываются принудительно.
- Успешный пинг не отменяет ошибку видео; возврат в автоматические режимы требует успешной повторной полной проверки.
- Успешная проверка balance сохраняется до следующего интервала подписки. Новые и внутренние переключения отменяют устаревшую проверку.
- Android: скрытая автоматическая проверка, беззвучное воспроизведение, ручной запуск без автовоспроизведения, прогресс в процентах.
- Перенесены исправления выбора lowest и зависания управления соединением.

Выпускаются только macOS Apple Silicon и Android. Windows остаётся на 4.1.33; macOS Intel не поддерживается.

Подпись macOS: локальная ad-hoc, без Apple notarization. Android: прежний локальный сертификат. Сборки и проверки выполнены локально.
