# ProxyYou 4.1.24

Отображение стратегии balance, проверенное в Apple Silicon, перенесено на
macOS Intel, Android / Android TV и Windows x64.

- Под меткой balance показана выбранная стратегия: «Поочерёдно»,
  «Согласованное хеширование» или «Закрепление сессий».
- Карточка не подписывается на меняющееся имя последнего сервера.
  Нажатие по-прежнему открывает список конфигураций.
- В lowest и при ручном выборе сохранены имя сервера и протокол.
- Пинг по-прежнему относится к последнему использованному серверу.

Маршрутизация, ядро и сохранение установленных соединений не изменены.
Windows поставляется одним EXE без WebView2 и проверки воспроизведения.
Пакеты macOS arm64 и x86_64 раздельные. Android подписан прежним ключом.
Все сборки и основные проверки выполняются локально; Android — с Java 25,
Windows — с временным файлом подкачки.
