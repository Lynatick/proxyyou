# ProxyYou 4.1.26

Исправлен планировщик пинга больших подписок.

- Устранена потеря заданий после заполнения очереди на 10 000 конфигураций.
- Проверки чередуются между 20 равными частями подписки через общий пул до 20 обработчиков.
- Ранее отвечавшие серверы без отметки недоступности перепроверяются первыми.
- Ручная проверка повышает приоритет существующего задания без дубликатов.
- Отключение отменяет большую очередь и отложенные повторы; неготовый транспорт не удерживает цикл.
- Сохранены правила недоступности, исключение из balance/lowest и открытые соединения.

Поддерживаются macOS Apple Silicon и Intel (раздельные ZIP), Android / Android TV
(единый APK для armv7, arm64 и x64), Windows x64 (установщик EXE).
На Windows проверка воспроизведения видео отключена.

macOS: локальная ad-hoc подпись, без нотарификации Apple.
Windows: установщик без цифровой подписи издателя.
Android: сохранён прежний сертификат подписи; возможно обновление поверх предыдущей версии.

Сборки выполнены локально; Android — Java 25, Windows — временный файл подкачки.
Страница загрузки: https://lynatick.github.io/proxyyou/
